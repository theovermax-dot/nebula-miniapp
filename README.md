# NEBULA Gaming — Telegram Mini App

Бронь ПК с живой картой зала, регистрация на турниры, акции с подпиской и админ-панель для персонала.
Стек: чистый HTML/CSS/JS (без сборки) + serverless-функции Vercel. Всё на бесплатных тарифах.

## Что внутри
**Гостям:** свободные места в реальном времени · бронь за 3 шага (время → длительность → места, можно несколько) · пакеты применяются автоматически, если дешевле · турниры с регистрацией команд · акции и подписка на уведомления · «Мои брони» с отменой.

**Персоналу** (вкладка «Профиль» → «Для персонала», или `/admin`): живой зал — тап по месту меняет статус (занят до…, ремонт) · брони: подтвердить / отклонить / пришёл / не пришёл · создание турниров и список участников · акции и рассылка подписчикам в Telegram.

## Режимы
- **Демо** (без настроек): всё работает, данные хранятся в браузере. PIN админки — `2828`.
- **Боевой**: с бесплатной базой Upstash Redis данные общие для всех, приходят уведомления в Telegram.

## Запуск (≈15 минут, бесплатно)

1. **GitHub.** Создайте репозиторий и загрузите в него содержимое этой папки (Add file → Upload files).
2. **Vercel.** vercel.com → Add New → Project → Import репозиторий → Deploy. Получите адрес вида `https://nebula-xxx.vercel.app` — демо уже работает.
3. **База.** В проекте Vercel: Storage → Create → Upstash (Redis) → Free → Connect to project. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
4. **Бот.** В @BotFather: `/newbot` → получите токен.
5. **Переменные** (Vercel → Settings → Environment Variables):

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_PIN` | свой PIN для входа персонала (вместо 2828!) |
| `ADMIN_IDS` | Telegram ID админов через запятую — они входят без PIN |
| `ADMIN_CHAT_ID` | ID чата персонала для уведомлений о бронях (добавьте бота в группу, напишите `/id`) |
| `WEBAPP_URL` | адрес с Vercel, например `https://nebula-xxx.vercel.app` |
| `WEBHOOK_SECRET` | любая случайная строка (по желанию) |

6. **Redeploy** (Deployments → ⋯ → Redeploy), затем откройте `https://ваш-адрес/api/setup?pin=ВАШ_ADMIN_PIN` — бот получит webhook и кнопку меню.
7. В @BotFather: `/newapp` (или Bot Settings → Configure Mini App) → укажите тот же адрес. Готово — откройте бота и нажмите «NEBULA».

Ссылки на разделы: `t.me/ВАШ_БОТ/app?startapp=book` (также `tours`, `promos`).

## Что поменять перед запуском
- `assets/js/core.js` → `seedDB`: демо-турниры, акции «День рождения» и «Командой дешевле», тестовые брони — это примеры, замените или удалите через админку.
- Логотип: сейчас текстовый знак NEBULA. Положите `logo.svg` клуба в `assets/` — подключу.
- Демо-симуляция гостей включена: выключите переключателем в «Зале», когда персонал начнёт отмечать места вручную.

## Структура
```
index.html            оболочка приложения
assets/app.css        стили и токены
assets/js/core.js     цены, пакеты, занятость, действия (общий код браузера и сервера)
assets/js/app.js      экраны гостя
assets/js/admin.js    админ-панель
assets/js/store.js    данные: сервер или демо в браузере
api/                  serverless-функции: state, action, bot (webhook), setup
```
